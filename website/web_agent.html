    03 / 10-Plane Pure-CPU Harness Integration (slm_harness)

    Rather than executing as an isolated prompt wrapper, SLM Web Agent is natively orchestrated by the SLMAgents 2.0 10-Plane Pure-CPU Harness (via slm_harness.runtime.legacy_bridge and CascadeRouter). Every call benefits from hybrid llama.cpp GGUF (Q4_K_M) + Quantized INT4/INT8 CPU execution, watermarked LRU memory governance, grammar-constrained decoding, and deterministic verification at $0 API cost:

    Harness PlaneSubsystemHow It Powers SLM Web Agent on Pure CPU
    Plane 6 CascadeRouter (<35ms) Stage 2 (DOM Action / Browser Navigation Intent) & Stage 3 (Embedding Margin)
    Plane 2 & 5 MemoryArena & Hybrid CPU Runtime Specialist Role: primary (Qwen3-4B GGUF Q4_K_M / Llama-3.2-3B INT4). Managed inside Watermark LRU MemoryArena (lite 2.6 GB / balanced 4.7 GB / power 8.2 GB) with zero-copy session sharing and automatic OOM tier step-down (8B -> 4B -> 3B -> 0.8B).
    Plane 7 & 8 Deterministic Verifier & Governance Plane 2 GBNF Action-Schema Constrained Decoding (CLICK, TYPE, SCROLL, FINISH) + Plane 8 L3_NETWORK Governance Gate
    Plane 1, 3 & 4 Kernel, Artifact Scratchpad & 4-Tier Memory SQLite WAL CheckpointStore (/fork, /rewind, /undo), content-addressed artifact://<sha12> handles to prevent prompt bloat, and hybrid SQLite FTS5 BM25 + HNSW vector memory.

    05 / Configuration & API Reference

    Constructor Parameters

    Instantiate SLMWebAgent with performance and runtime options:

    ParameterType / DefaultDescription
    headlessbool | TrueRun browser in headless background mode. Default: True.
    temperaturefloat | 0.0Action planning temperature. Default: 0.0.
    top_pfloat | 0.9Nucleus sampling cutoff. Default: 0.9.
    max_tokensint | 256Max token output limit. Default: 256.
    n_threadsint | 4CPU threads for model execution. Default: 4.

    Methods

    Method SignatureReturn TypeDescription
    browse(goal, start_url, ...)dictExecutes multi-step Playwright web browsing tasks autonomously.

    Execution Parameters

    Complete list of execution parameters accepted by the primary agent method:

    ParameterType / DefaultDescription
    goalstrTarget browser automation goal description.
    start_urlstrInitial Web URL to navigate to.
    system_promptstr | NoneCustom system instruction prompt override. Default: None.
    user_inputstr | NoneOptional additional user form fill values. Default: None.
    temperaturefloat | 0.0Sampling temperature. Default: 0.0.
    top_pfloat | 0.9Nucleus sampling probability. Default: 0.9.
    max_tokensint | 256Maximum token limit. Default: 256.

    Quick Start

    Python Example
    from slm_web_agent import SLMWebAgent

web = SLMWebAgent(headless=True, n_threads=4)
res = web.browse(
    goal="Navigate to portal signup and enter test email",
    start_url="https://portal.slmagents.ai/signup",
    system_prompt="Wait 2 seconds after submit",
    user_input="Email: dev@slmagents.ai",
    temperature=0.0,
    top_p=0.9,
    max_tokens=256
)
print(res)
