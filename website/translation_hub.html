    03 / 10-Plane Pure-CPU Harness Integration (slm_harness)

Every call benefits from hybrid llama.cpp GGUF (Q4_K_M) + Quantized INT4/INT8 CPU execution, watermarked LRU memory governance, grammar-constrained decoding, and deterministic verification at $0 API cost:

    Plane 2 & 5 MemoryArena & Hybrid CPU Runtime Specialist Role: primary (Qwen3-4B GGUF Q4_K_M / Aya-23 / Multilingual INT4). Managed inside Watermark LRU MemoryArena (lite 2.6 GB / balanced 4.7 GB / power 8.2 GB) with zero-copy session sharing and automatic OOM tier step-down (8B -> 4B -> 3B -> 0.8B).

    Plane 1, 3 & 4 Kernel, Artifact Scratchpad & 4-Tier Memory SQLite WAL CheckpointStore (/fork, /rewind, /undo), content-addressed artifact://<sha12> handles to prevent prompt bloat, and hybrid SQLite FTS5 BM25 + HNSW vector memory.

    05 / Configuration & API Reference

    Constructor Parameters

    Instantiate SLMTranslationHub with performance options:

    ParameterType / DefaultDescription
    model_pathstr | NoneExplicit path to GGUF (Q4_K_M) or quantized ONNX model weights. If omitted, managed automatically by the 10-Plane Harness MemoryArena.
    cache_dirstr | NoneDirectory to store model weights offline. Defaults to ~/.cache/slm-translation/. Also settable via SLM_TRANSLATION_HUB_CACHE_DIR.
    n_threadsint | 4CPU thread count for 10-Plane Harness inference (auto-tuned to physical P-cores). Optimize for CPU core count. Also settable via SLM_TRANSLATION_HUB_N_THREADS.

    Methods

    Method SignatureReturn TypeDescription
    translate(text, source_lang='en', target_lang='hi', system_prompt=None, user_input=None)strTranslates characters locally to target languages, ensuring syntax integrity is preserved.

    Method Parameters (Execution Customization)

    All main execution methods accept optional system routing parameters:

    ParameterType / DefaultDescription
    system_promptstr | NoneOptional custom system prompt instruction to override the default system template response parameters.
    user_inputstr | NoneOptional additional user-supplied target text variables or contextual keys.

    Quick Start

    from slm_translation import SLMTranslationHub

hub = SLMTranslationHub()
translated = hub.translate(
    "hello world",
    source_lang="en",
    target_lang="hi",
    system_prompt="Strict dialect formatting",
    user_input="Formal script conversion"
)
print(translated)

    Configure agent parameters globally using environment values:

    Environment VariableDefaultPurpose

    SLM_TRANSLATION_HUB_CACHE_DIR~/.cache/slm-translation/Default directory to store local GGUF (Q4_K_M) and quantized INT4/INT8 model weights (shared with ~/.slm_harness/models).

    CPU Performance Tuning

    To run the SLMTranslationHub engine efficiently on CPU under 1.5 GB memory footprint:

    • Match Threads to Core Count: Set n_threads or SLM_TRANSLATION_HUB_N_THREADS to match the physical CPU core count.
    • Sequential Processing: Avoid concurrent processing when batch files are large.
    • Garbage Collection: Clear variables and run gc.collect() to release model RAM blocks after execution.
