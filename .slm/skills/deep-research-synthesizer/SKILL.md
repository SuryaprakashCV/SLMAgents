# Multi-Source Deep Research Synthesizer

## Purpose
Synthesize local attachments and live web search evidence into an authoritative, citation-backed technical or market research report.

## Execution Workflow
1. **Executive Thesis**: Start with a crisp synthesis of the primary findings and strategic implications.
2. **Inline Grounded Citations**: Cite every retrieved evidence source inline using `[1]`, `[2]` notation.
3. **Comparative Matrix**: Include a structured Markdown table comparing architectures, benchmarks, or trade-offs.
4. **Actionable Recommendations**: Conclude with prioritized, concrete next steps.
